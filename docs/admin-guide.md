# Посібник адміністратора MobileStore

> **Для кого цей посібник.** Він написаний для власника магазину та майбутніх
> співробітників, які **не є програмістами**. Ви не маєте нічого знати про код,
> бази даних чи SEO — усе пояснено простою мовою, крок за кроком. Мета: щоб будь-хто
> міг самостійно керувати магазином через адмін-панель і нічого не зламати.
>
> **Коли це потрібно.** Цей посібник потрібен **ще до першого запуску** — навіть до
> тестового (dev) розгортання. Тобто ви маєте вміти працювати з панеллю з першого дня,
> без допомоги розробника.
>
> **Де взяти доступ і допомогу.** Адресу адмін-панелі (посилання) та ваш логін/пароль
> надає розробник під час налаштування. Якщо щось не працює, кнопка недоступна або
> з'явилася незрозуміла помилка — не намагайтеся «полагодити» це через базу даних;
> зверніться до розробника і опишіть, що саме ви робили.

> **Структура посібника.** Ця частина (частина 1) охоплює **каталог і продажі**: товари,
> категорії, групи, бренди, пристрої, характеристики, замовлення, користувачів і промокоди.
> Розділи про контент (сторінки, блог, банери), повідомлення, підписників, контакти,
> SEO-налаштування, FAQ, дашборд і чек-лист перед запуском додаються у частині 2
> (див. розділ [«Що далі»](#chastyna-2) у кінці).

## 1. Вхід у панель і навігація

### Що це

Адмін-панель — це окремий сайт (не той, що бачать покупці), через який ви керуєте всім
магазином: товарами, замовленнями, клієнтами, контентом. Покупці її не бачать і не
можуть туди зайти.

### Як увійти

1. Відкрийте посилання на адмін-панель, яке надав розробник (сторінка входу).
2. Введіть **Електронну пошту** та **Пароль** вашого адміністраторського акаунта.
3. Натисніть **Увійти**.

> _(скріншот: сторінка входу з полями «Електронна пошта», «Пароль» і кнопкою «Увійти»)_

**Навіщо саме адмін-акаунт:** до панелі пускає тільки акаунт із роллю
«Адміністратор». Якщо ви спробуєте увійти звичайним акаунтом покупця, побачите
повідомлення «Цей акаунт не має прав адміністратора».

### Огляд навігації (бічне меню)

Зліва завжди видно бічне меню (sidebar). Верхня частина — основні розділи, нижня —
налаштування.

**Основні розділи (зверху вниз):**

| Пункт меню        | Що всередині                                               |
| ----------------- | ---------------------------------------------------------- |
| **Панель**        | Головний екран зі зведеною статистикою (дашборд).          |
| **Товари**        | Створення й редагування товарів.                           |
| **Групи товарів** | Об'єднання варіантів одного товару (напр. кольори).        |
| **Категорії**     | Дерево категорій каталогу.                                 |
| **Бренди**        | Виробники аксесуарів (Baseus, Anker тощо).                 |
| **Пристрої**      | Гаджети (iPhone, Samsung…) для сумісності аксесуарів.      |
| **Промокоди**     | Купони зі знижками.                                        |
| **Сторінки**      | Службові сторінки (про доставку, гарантію…) — _частина 2_. |
| **Банери**        | Рекламні блоки на головній — _частина 2_.                  |
| **Блог**          | Статті блогу — _частина 2_.                                |
| **Замовлення**    | Усі замовлення покупців.                                   |
| **Відгуки**       | Модерація відгуків про товари.                             |
| **Повідомлення**  | Вхідні звернення з форми контактів — _частина 2_.          |
| **Користувачі**   | Клієнти та адміністратори.                                 |
| **Підписники**    | Підписники email-розсилки — _частина 2_.                   |

**Нижня частина меню:** **Контакти** (телефон/пошта/графік магазину — _частина 2_) і
**Налаштування**.

> _(скріншот: бічне меню з усіма пунктами; поряд із «Повідомлення» — лічильник нових)_

Біля пункту **Повідомлення** з'являється червоний лічильник, коли є непрочитані
звернення від клієнтів.

⚠️ **Підводні камені**

- Панель повністю **українською** — усі назви кнопок нижче збігаються з тим, що ви
  бачите на екрані.
- Якщо після кількох натискань «оновити сторінку» (F5) вас несподівано «викидає» —
  просто увійдіть ще раз; сесія коротка з міркувань безпеки.

## 2. Основні поняття (глосарій)

Кілька слів трапляються всюди в панелі. Прочитайте цей розділ один раз — далі буде легше.

- **Активний / Неактивний (перемикач видимості).** Майже кожен об'єкт (товар,
  категорія, бренд, промокод…) має статус **Активний** або **Неактивний**.
  «Неактивний» = тимчасово прихований від покупців, але **дані нікуди не зникають**.
  Ви будь-коли можете знову зробити його активним. Це головний спосіб «прибрати щось із
  вітрини», не втрачаючи його.
- **Видалення (насправді його майже немає).** Для товарів, категорій, брендів,
  користувачів і замовлень **немає кнопки «видалити назавжди»**. Замість цього ви їх
  **деактивуєте** (ховаєте). Так історія замовлень і статистика залишаються цілими.
  (Кнопка «Видалити» є лише в контентних розділах — сторінки, блог, банери, зображення
  товару — про них у частині 2.)
- **Slug (частина адреси).** Це «людиночитабельний» шматок посилання, напр. у
  `mobilestore.ua/products/**chohol-silikonovyi**` slug — це `chohol-silikonovyi`.
  Якщо залишити поле порожнім, система згенерує slug автоматично з назви. **Змінювати
  slug вже опублікованого товару небажано** — старе посилання перестане працювати.
- **Артикул (SKU).** Ваш внутрішній код товару для обліку (напр. `CASE-IP15-BLK`).
  Необов'язковий, але зручний для складу.
- **Ціна та стара ціна.** «Ціна» — це те, що платить покупець. «Стара ціна» (більша) —
  закреслена ціна поруч, яка показує розмір знижки. Стару ціну заповнюйте лише коли є
  реальна акція.
- **Запас (stock).** Скільки одиниць товару доступно. Коли запас = 0, кнопка «Додати в
  кошик» на вітрині зникає. Запас **автоматично зменшується** з кожним замовленням.
- **Група та позиція.** «Група товарів» об'єднує варіанти одного товару (напр. один
  чохол у 5 кольорах). Кожен варіант — окрема **позиція** (окремий товар), але на
  вітрині вони показані однією карткою з перемикачами.
- **Вісь (axis).** Характеристика, за якою відрізняються позиції в групі (напр. `колір`,
  `розмір`). Осі задаються в групі; значення осі (`синій`) — у кожному товарі.
- **Бренд vs Пристрій.** **Бренд** — хто виробив аксесуар (Baseus, Anker). **Пристрій** —
  гаджет, до якого аксесуар підходить (iPhone 15). Це два різні розділи, не плутайте.
- **SEO.** Скорочення від «оптимізація для пошукових систем» — це те, як ваш магазин
  виглядає в Google. Ви можете нічого не заповнювати: система підставить назви
  автоматично. Заповнюйте SEO-поля лише якщо хочете точніший текст.
  - **SEO-заголовок (meta title)** — заголовок сторінки у вкладці браузера та в
    результатах Google.
  - **SEO-опис (meta description)** — короткий опис під заголовком у результатах Google.
- **Статус публікації: Чернетка / Заплановано / Опубліковано.** Стосується контенту
  (сторінки, блог, банери — _частина 2_):
  - **Чернетка** — видно тільки вам в адмінці, покупці не бачать.
  - **Заплановано** — з'явиться автоматично у вказану дату й час.
  - **Опубліковано** — видно всім на сайті прямо зараз.

## 3. Товари

### Що це

Розділ **Товари** — серце магазину. Тут ви створюєте картки товарів, задаєте ціни,
запас, зображення, категорію та все інше, що бачить покупець.

> _(скріншот: список товарів із колонками «Назва», «Категорія», «Ціна», «Статус»,
> «Створено» і кнопкою «Редагувати»)_

Список показує і **активні, і деактивовані** товари (на відміну від вітрини). Ви можете:

- шукати товар у полі пошуку зверху;
- сортувати за назвою, ціною чи датою (клік по заголовку колонки);
- гортати сторінки (по 10 товарів).

### Щоб створити товар

1. Відкрийте **Товари** в меню.
2. Натисніть **Додати товар** (вгорі праворуч).
3. Заповніть форму (докладніше про поля — нижче) і натисніть **Створити товар**.
4. Вас повернуть до списку з повідомленням «Товар створено».
5. **Щоб додати зображення, характеристики та сумісність — відкрийте цей товар знову
   через «Редагувати»** (див. підводні камені).

### Щоб відредагувати товар

1. У списку натисніть **Редагувати** напроти потрібного товару.
2. Змініть потрібні поля.
3. Натисніть **Зберегти зміни**.

### Ключові поля форми товару

| Поле                | Що вводити                                                                                               |
| ------------------- | -------------------------------------------------------------------------------------------------------- |
| **Назва**           | Обов'язкова. Повна назва товару, як її бачитиме покупець.                                                |
| **Slug**            | Частина адреси. Залиште порожнім — згенерується з назви (система покаже підказку «Буде згенеровано: …»). |
| **Опис**            | Текст опису товару (до 5000 символів).                                                                   |
| **Ціна**            | Обов'язкова, більша за 0. Ціна для покупця у гривнях.                                                    |
| **Стара ціна**      | Необов'язкова. Закреслена «доакційна» ціна. Заповнюйте лише для реальної знижки.                         |
| **Артикул**         | Ваш внутрішній код (SKU), необов'язковий.                                                                |
| **Категорія**       | Обов'язкова. Оберіть **підкатегорію** (див. підводні камені).                                            |
| **Запас**           | Скільки штук на складі. Ціле число ≥ 0.                                                                  |
| **Порядок позиції** | Впливає на порядок показу в межах групи. Можна лишити 0.                                                 |
| **Група**           | Необов'язково. «Без групи» — звичайний товар. Оберіть групу, щоб зробити товар варіантом.                |
| **Бренд**           | Необов'язково. Виробник аксесуара.                                                                       |
| **Атрибути**        | Пари «ключ/значення» для позицій групи (напр. `color` / `blue`). Див. розділ [Групи](#5-grupy).          |
| **Активний**        | Галочка «показувати в магазині». Знята галочка = товар прихований.                                       |

> _(скріншот: форма створення товару з полями «Назва», «Ціна», «Стара ціна»,
> «Категорія», «Запас», «Група», «Бренд»)_

### Зображення, характеристики та сумісність (тільки на екрані редагування)

Коли ви **відкриваєте вже створений товар на редагування**, під формою з'являються ще
три блоки:

- **Зображення товару** — завантаження, порядок, головне фото, видалення (див. нижче).
- **Характеристики** — структуровані параметри товару (див. розділ [8](#8-harakterystyky)).
- **Сумісні пристрої** — до яких гаджетів підходить аксесуар (див. розділ [7](#7-prystroi)).

#### Щоб додати й упорядкувати зображення

1. У блоці **Зображення товару** натисніть **Завантажити зображення**.
2. Оберіть один або кілька файлів (JPEG, PNG, WebP або GIF, до 5 МБ кожен).
3. Після завантаження наведіть на зображення, щоб побачити кнопки:
   - стрілки **ліворуч/праворуч** — змінити порядок;
   - **зірочка** — зробити фото головним (обкладинкою);
   - **кошик** — видалити (з підтвердженням).

> _(скріншот: сітка зображень товару з позначкою «Головне» на першому фото)_

**Навіщо головне фото:** саме воно показується на картці товару в каталозі та першим у
галереї.

### Перегляд деактивованого товару

Деактивований товар не видно покупцям, але ви можете переглянути, як він виглядатиме:

1. На екрані редагування натисніть посилання **Переглянути** (вгорі праворуч).
2. Відкриється сторінка товару в новій вкладці зі службовим банером угорі: «Цей товар
   деактивований і не відображається для покупців. Це службовий перегляд.»

⚠️ **Підводні камені**

- **Спершу збережіть товар — потім додавайте фото, характеристики й сумісність.** На
  екрані _створення_ цих блоків немає; вони з'являються лише коли товар уже існує і ви
  відкрили його на _редагування_.
- **У списку категорій видно лише кінцеві підкатегорії, а не батьківські «кошики».**
  Товар завжди прив'язується до конкретної підкатегорії (напр. «Чохли для iPhone», а не
  просто «Чохли»). Якщо не бачите потрібну категорію — можливо, у неї є підкатегорії;
  оберіть точнішу.
- **Немає кнопки «видалити товар».** Щоб прибрати товар із вітрини — зніміть галочку
  **Активний** (або скористайтеся перемикачем статусу прямо в списку). Дані збережуться.
- **Запас зменшується автоматично** з кожним замовленням. Коли він дійде до 0, товар на
  вітрині стане недоступним для купівлі.
- Не плутайте **Атрибути** (значення осей для варіантів групи, напр. колір) із
  **Характеристиками** (структуровані параметри на кшталт матеріалу чи потужності —
  розділ [8](#8-harakterystyky)).

> Технічні деталі поведінки: TASK-142 (варіанти/позиції), TASK-155 (службовий перегляд),
> TASK-230 (адмін-список показує й приховані товари), TASK-236 (вибір підкатегорій).

## 4. Категорії

### Що це

Категорії — це дерево розділів каталогу (напр. «Аксесуари» → «Чохли» → «Чохли для
iPhone»). Покупці орієнтуються по ньому у меню й фільтрах. Дерево може мати **до трьох
рівнів**.

> _(скріншот: список категорій із колонками «Назва», «Slug», «Батьківська», «Товари»
> (кількість), «Порядок», «Статус»)_

### Щоб створити категорію

1. Відкрийте **Категорії** → **Додати категорію**.
2. Заповніть поля (нижче) і натисніть **Створити категорію**.

### Ключові поля

| Поле                            | Що вводити                                                                                       |
| ------------------------------- | ------------------------------------------------------------------------------------------------ |
| **Назва**                       | Обов'язкова. Як категорія називається в меню.                                                    |
| **Slug**                        | Частина адреси; лишіть порожнім для автогенерації.                                               |
| **Опис**                        | Необов'язковий текст про категорію.                                                              |
| **URL зображення**              | Посилання на картинку категорії (необов'язково).                                                 |
| **Батьківська категорія**       | «Коренева (без батьківської)» — верхній рівень. Інакше оберіть, під якою категорією вона стоїть. |
| **Порядок сортування**          | Менше число — вище у списку.                                                                     |
| **SEO-заголовок (meta title)**  | Необов'язково. Порожнє — використається назва категорії.                                         |
| **SEO-опис (meta description)** | Необов'язковий короткий опис для Google.                                                         |
| **Активна**                     | Показувати в магазині чи ні.                                                                     |

> _(скріншот: форма категорії з полем «Батьківська категорія» і SEO-полями)_

### Характеристики категорії (шаблони)

На екрані **редагування** категорії внизу є окремий блок **Характеристики** — це
_шаблони_ параметрів для товарів цієї категорії (напр. «Матеріал», «Сумісність із
MagSafe»). Вони **успадковуються підкатегоріями**. Докладно — у розділі
[8](#8-harakterystyky).

⚠️ **Підводні камені**

- Категорія **не може бути власною батьківською** — вона автоматично прибрана зі списку
  батьків, щоб не утворилося «кільце».
- **Товари прив'язуються до кінцевих підкатегорій**, а не до кореневих. Плануйте дерево
  так, щоб товари мали куди «лягти».
- Деактивація категорії ховає її з меню й фільтрів; товари в ній не видаляються, але
  стають менш доступними для навігації.
- SEO-поля порожні за замовчуванням — і це нормально: без них Google побачить назву
  категорії. Заповнюйте, лише якщо хочете інший текст.

> Технічні деталі: TASK-222 (архітектура дерева ≤3 рівні), TASK-238 (виправлення
> зміни батьківської категорії), TASK-240 / plan 116 (підключення SEO-полів категорії
> до вітрини).

<a id="5-grupy"></a>

## 5. Групи товарів

### Що це

**Група товарів** об'єднує кілька варіантів одного товару в одну картку на вітрині.
Приклад: один силіконовий чохол існує в 5 кольорах. Замість 5 окремих карток покупець
бачить **одну** картку з перемикачем кольору. Кожен колір — це окрема **позиція**
(окремий товар зі своєю ціною й запасом), але зібрані вони в одну групу.

> _(скріншот: список груп із колонками «Назва», «Осі», «Позиції», «Статус»)_

### Щоб створити групу

1. Відкрийте **Групи товарів** → **Додати групу**.
2. Введіть **Назву** групи (напр. «Чохол Silicone Case»).
3. Додайте **Осі атрибутів** — це характеристики, за якими відрізняються варіанти
   (напр. `color`, `набір`). Порядок осей = порядок перемикачів на вітрині.
4. Натисніть **Зберегти групу**.

### Як наповнити групу позиціями

Позиції **не додаються на екрані групи**. Натомість:

1. Створіть (або відкрийте) товар-варіант у розділі **Товари**.
2. У полі **Група** оберіть вашу групу.
3. У блоці **Атрибути** товару впишіть значення осей: **ключ** = назва осі (напр.
   `color`), **значення** = конкретне (напр. `blue`).
4. Повторіть для кожного варіанта.

На екрані редагування групи знизу є список **«Позиції в цій групі»**. Поки ви не
призначили жодного товару, там буде підказка: «Позицій ще не призначено. Призначте товар
до цієї групи у селекторі "Група" форми товару.»

> _(скріншот: форма групи з полем «Назва» та списком осей; нижче — блок «Позиції в цій
> групі»)_

⚠️ **Підводні камені**

- **Ключ атрибута в товарі має точно збігатися з назвою осі в групі.** Якщо в групі вісь
  зветься `color`, а в товарі ви впишете `колір` — вітрина не зіставить їх, і перемикач
  працюватиме неправильно.
- Порядок осей у групі задає порядок перемикачів на сторінці товару — розставте
  найважливіше першим.
- Група теж має статус **Активна** — неактивна група не показує варіанти на вітрині.

> Технічні деталі: TASK-142 (варіанти як позиції групи), plan 060.

<a id="6-brendy"></a>

## 6. Бренди

### Що це

**Бренд** — виробник аксесуара (Baseus, Anker, Spigen…). Покупці фільтрують каталог за
брендом і бачать блок «Популярні бренди».

> _(скріншот: список брендів із пошуком, фільтром за статусом і колонками «Назва»,
> «Slug», «Статус»)_

### Щоб створити бренд

1. Відкрийте **Бренди** → **Додати бренд**.
2. Заповніть поля:
   - **Назва** — обов'язкова;
   - **Slug** — лишіть порожнім для автогенерації;
   - **Логотип (URL)** — посилання на лого (необов'язково);
   - **Активний** — показувати у магазині.
3. Натисніть **Створити бренд**.

### Як прив'язати бренд до товару

Бренд обирається **у формі товару** в полі **Бренд** (не тут). Один бренд можна
призначити багатьом товарам.

Список брендів можна фільтрувати за статусом (**Усі статуси / Активний / Прихований**)
та шукати за назвою. Приховати чи активувати бренд можна прямо у списку.

⚠️ **Підводні камені**

- **Бренд — це не пристрій.** Бренд = хто виготовив аксесуар. Сумісність із телефонами
  задається окремо в розділі [Пристрої](#7-prystroi).
- Приховування бренду прибирає його з фільтра на вітрині, але не чіпає товари, яким він
  призначений.

> Технічні деталі: TASK-189, plan 110.

<a id="7-prystroi"></a>

## 7. Пристрої та сумісність

### Що це

Розділ **Пристрої** описує гаджети, до яких підходять ваші аксесуари: **Бренди
пристроїв** (Apple, Samsung, Xiaomi…) і всередині них — **Моделі пристроїв** (iPhone 15,
Galaxy S24…). Це окрема від товарних брендів «вісь сумісності»: вона дає покупцям фільтр
«підбери аксесуар для мого пристрою».

> _(скріншот: сторінка «Пристрої» з двома вкладками — «Бренди» і «Моделі»)_

### Щоб додати бренд пристрою

1. **Пристрої** → вкладка **Бренди** → **Додати бренд**.
2. Заповніть: **Назва бренду**, **Slug** (авто), **Порядок сортування**, **Активний**.
3. Збережіть.

### Щоб додати модель пристрою

1. **Пристрої** → вкладка **Моделі** → **Додати модель**.
2. Заповніть:
   - **Бренд пристрою** — обов'язково (до якого бренду належить модель);
   - **Назва моделі** (напр. iPhone 15 Pro);
   - **Slug** — авто;
   - **Серія** (напр. «iPhone 15») — необов'язково, для групування;
   - **Рік випуску** — необов'язково;
   - **Активна**.
3. Збережіть.

### Щоб задати сумісність товару з пристроями

1. Відкрийте потрібний **товар на редагування**.
2. Знайдіть блок **Сумісні пристрої** (під формою товару).
3. Побачите список моделей, згрупований за брендами пристроїв. Поставте галочки навпроти
   всіх моделей, до яких підходить аксесуар.
4. Натисніть **Сумісні пристрої** (кнопка збереження цього блоку).
5. Якщо товар входить у групу, з'явиться кнопка **Застосувати до всіх позицій групи** —
   вона скопіює цей самий набір сумісності на всі варіанти групи (щоб не проставляти
   вручну кожному кольору).

> _(скріншот: блок «Сумісні пристрої» з чекбоксами моделей, згрупованими за брендами, і
> кнопкою «Застосувати до всіх позицій групи»)_

⚠️ **Підводні камені**

- **Спершу створіть бренди й моделі пристроїв, потім проставляйте сумісність.** Якщо
  моделей ще немає, у блоці товару буде напис «Спершу створіть бренди та моделі
  пристроїв».
- Кнопка збереження сумісності **окрема** від кнопки «Зберегти зміни» товару. Натисніть
  саме її, інакше галочки не збережуться.
- Не плутайте цей розділ із **Брендами** (розділ [6](#6-brendy)): там — виробники
  аксесуарів, тут — гаджети для сумісності.

> Технічні деталі: TASK-190, plan 111.

<a id="8-harakterystyky"></a>

## 8. Характеристики (структуровані)

### Що це

**Характеристики** — це структуровані параметри товару (матеріал, потужність, довжина
кабелю тощо), однакові для всіх товарів однієї категорії. Вони працюють у два кроки:

1. **Шаблон** створюється **на категорії** — які саме параметри бувають у товарів цієї
   категорії.
2. **Значення** заповнюються **на товарі** — конкретні дані для кожного товару.

Це дає акуратну вкладку «Характеристики» на сторінці товару й може ставати **фільтром**
каталогу.

### Крок 1. Шаблони характеристик (на категорії)

1. Відкрийте **Категорії** → потрібну категорію → **Редагувати**.
2. Внизу знайдіть блок **Характеристики** → **Додати характеристику**.
3. У вікні заповніть:
   - **Ключ (лат.)** — латиницею, напр. `material` (внутрішня назва);
   - **Назва** — як бачитиме покупець, напр. «Матеріал»;
   - **Тип** — **Текст**, **Число**, **Так/Ні** або **Вибір зі списку**;
   - **Одиниця** — необов'язково (напр. `Вт`, `мм`);
   - **Значення** (лише для типу «Вибір зі списку») — кожен варіант із нового рядка;
   - **Використовувати як фільтр каталогу** — якщо ввімкнути, за цією характеристикою
     покупці зможуть фільтрувати товари.
4. Збережіть. Порядок характеристик можна міняти стрілками ↑/↓.

> _(скріншот: блок «Характеристики» на категорії зі списком шаблонів і позначкою
> «Фільтр»)_

**Навіщо:** заданий один раз на категорії шаблон **успадковується всіма
підкатегоріями** — не треба повторювати його для кожної.

### Крок 2. Значення характеристик (на товарі)

1. Відкрийте **товар на редагування**.
2. Знайдіть блок **Характеристики** (під формою).
3. Для кожного параметра з'явиться відповідне поле (текст, число, галочка або список).
   Заповніть потрібні.
4. Натисніть **Зберегти характеристики**.

> _(скріншот: блок «Характеристики» на товарі з полями різних типів і кнопкою «Зберегти
> характеристики»)_

⚠️ **Підводні камені**

- **Спочатку шаблони на категорії — потім значення на товарі.** Якщо в категорії товару
  немає жодного шаблону, у блоці товару буде напис «Для категорії цього товару ще не
  задано жодного шаблону характеристик».
- Кнопка **«Зберегти характеристики» — окрема** від збереження самого товару.
- Якщо змінити категорію товару, набір характеристик зміниться на шаблони нової
  категорії (значення зі співпадаючими ключами збережуться).
- Не плутайте з полем **Атрибути** у формі товару — то значення осей для варіантів
  групи, а не структуровані характеристики.

> Технічні деталі: TASK-191, plan 112.

## 9. Замовлення

### Що це

Розділ **Замовлення** показує всі покупки клієнтів. Тут ви відстежуєте виконання
замовлень і статус оплати.

> _(скріншот: список замовлень із колонками «Замовлення», «Клієнт», «Статус», «Оплата»,
> «Сума», «Позиції», «Створено» і фільтром за статусом)_

Список можна відфільтрувати за статусом (**Усі статуси** або конкретний).

### Щоб переглянути й опрацювати замовлення

1. Відкрийте **Замовлення** і натисніть на потрібне (або перейдіть на його сторінку).
2. На сторінці замовлення видно: товари, дані клієнта, підсумок (проміжна сума, знижка,
   доставка, податок, разом), адреси доставки й оплати, примітки.
3. Керуйте замовленням двома **незалежними** перемикачами (див. нижче).

> _(скріншот: сторінка замовлення з двома блоками — «Змінити статус» і «Статус оплати»)_

### Статуси замовлення

Оберіть новий статус у списку **«Змінити статус…»**. Доступні статуси:

| Статус                   | Значення                                  |
| ------------------------ | ----------------------------------------- |
| **Очікує підтвердження** | Нове, ще не підтверджене замовлення.      |
| **Підтверджено**         | Ви прийняли замовлення в роботу.          |
| **В обробці**            | Комплектується/готується до відправлення. |
| **Відправлено**          | Передане службі доставки.                 |
| **Доставлено**           | Отримане клієнтом.                        |
| **Скасовано**            | Замовлення скасоване.                     |
| **Повернення коштів**    | Кошти повернено клієнту.                  |

Ви маєте **повний ручний контроль** — можна перевести замовлення в будь-який статус
(немає жорсткої послідовності). Відповідальність за логічність переходів — на вас.

### Статус оплати

Окремий перемикач **«Змінити статус оплати…»**:

| Статус оплати       | Значення              |
| ------------------- | --------------------- |
| **Очікує оплати**   | Гроші ще не надійшли. |
| **Оплачено**        | Оплата підтверджена.  |
| **Помилка оплати**  | Оплата не пройшла.    |
| **Кошти повернено** | Оплату повернено.     |

**Навіщо це окремо:** статус замовлення (виконання) і статус оплати — різні речі. Зміна
одного **не змінює** інший. Позначайте «Оплачено» вручну, коли підтвердили надходження
коштів.

⚠️ **Підводні камені**

- **Позначка «Оплачено» важлива для статистики.** Дашборд рахує виручку й «хіти
  продажів» лише за **оплаченими** замовленнями. Якщо забути позначити оплату, звіти
  занизять показники.
- **Обережно зі скасуванням і поверненням у роботу.** Коли ви скасовуєте замовлення,
  товари **повертаються на склад**. Якщо потім спробувати «оживити» скасоване замовлення,
  система знову спише запас — і якщо за цей час товар **розкупили**, повернення буде
  відхилено (замовлення лишиться скасованим). Це захист від продажу того, чого немає.
- Позиції замовлення **не редагуються** після створення — сторінка замовлення показує їх
  лише для перегляду.

> Технічні деталі: TASK-129 (українські назви статусів), TASK-151 (повний ручний
> контроль статусів), TASK-228 (захист складу при скасуванні/поверненні в роботу).

<a id="10-korystuvachi"></a>

## 10. Користувачі

### Що це

Розділ **Користувачі** — усі акаунти: клієнти та адміністратори. Тут можна знайти
клієнта, переглянути його дані й за потреби **заблокувати (деактивувати)** акаунт.

> _(скріншот: список користувачів із пошуком, фільтрами «за роллю» і «за статусом» та
> колонками «Електронна пошта», «Ім'я», «Роль», «Статус», «Дата реєстрації»)_

Список можна:

- шукати за поштою або іменем;
- фільтрувати за роллю (**Усі ролі / Клієнт / Адміністратор**);
- фільтрувати за статусом (активні/неактивні).

### Ролі

- **Клієнт** — звичайний покупець; **не має** доступу до адмін-панелі.
- **Адміністратор** — має доступ до цієї панелі й керує магазином.

### Щоб заблокувати чи розблокувати користувача

1. Відкрийте картку користувача (натисніть на рядок у списку).
2. У блоці **Статус акаунта** натисніть:
   - **Деактивувати** (червона кнопка) — заблокувати вхід;
   - **Активувати** — відновити доступ.

> _(скріншот: картка користувача з роллю, статусом і кнопкою «Деактивувати»)_

**Навіщо:** деактивація миттєво позбавляє користувача змоги увійти (напр. при
зловживаннях), але **зберігає всі його дані та історію замовлень**.

⚠️ **Підводні камені**

- **Ви не можете деактивувати власний акаунт** — кнопка для себе неактивна (щоб не
  заблокувати самі себе).
- **Деактивація — це не видалення.** Акаунт і його замовлення залишаються; користувач
  просто не може увійти. Кнопки «видалити користувача» немає.
- **Зміна ролі (зробити когось адміністратором) у панелі недоступна** — роль лише
  показана й доступна для фільтра. Щоб призначити нового адміністратора, зверніться до
  розробника. Будьте обережні: адміністратор має повний доступ до магазину.

> Технічні деталі: керування користувачами — Phase 4, plan 029.

<a id="11-promokody"></a>

## 11. Промокоди

### Що це

**Промокоди** (купони) — коди на знижку, які покупець вводить у кошику (напр. `SUMMER10`).

> _(скріншот: список промокодів із колонками «Код», «Тип», «Значення», «Використано»,
> «Діє до», «Статус»)_

Список показує, скільки разів кожен код використано (`використано / ліміт`) і до якої
дати він діє.

### Щоб створити промокод

1. Відкрийте **Промокоди** → **Додати промокод**.
2. Заповніть форму (нижче) і натисніть **Створити промокод**.

### Ключові поля

| Поле                             | Що вводити                                                     |
| -------------------------------- | -------------------------------------------------------------- |
| **Код**                          | Сам купон (напр. `SUMMER10`). Вводиться великими літерами.     |
| **Тип знижки**                   | **Відсоток (%)** або **Фіксована сума (₴)**.                   |
| **Значення**                     | Для відсотка — число 1–100; для фіксованої — сума у гривнях.   |
| **Мінімальна сума замовлення**   | Необов'язково. Купон спрацює лише від цієї суми.               |
| **Глобальний ліміт використань** | Необов'язково. Скільки разів усього можна застосувати код.     |
| **Ліміт на користувача**         | Необов'язково. Скільки разів код може використати один клієнт. |
| **Активний від**                 | Необов'язково. Дата початку дії.                               |
| **Діє до**                       | Необов'язково. Дата завершення.                                |
| **Активний**                     | Чи діє код зараз.                                              |

> _(скріншот: форма промокоду з вибором типу «Відсоток / Фіксована сума» і полями
> лімітів та дат)_

### Щоб вимкнути промокод

У списку натисніть **Деактивувати** навпроти коду (або зніміть галочку «Активний» у
формі). Код перестане працювати, але залишиться в історії.

⚠️ **Підводні камені**

- **Код не можна змінити після створення** — у режимі редагування поле коду заблоковане.
  Якщо потрібен інший код, створіть новий.
- **Відсоток має бути в межах 1–100.** Для великих знижок фіксованою сумою
  використовуйте тип «Фіксована сума (₴)».
- **Дата початку має передувати даті завершення** — інакше форма покаже помилку.
- Промокоди **деактивують, а не видаляють** — так зберігається статистика використань.

> Технічні деталі: TASK-079 (промокоди), plan 041/042; TASK-219 / plan 097 (пропозиція
> купонів v2).

- **FAQ** — часті запитання-відповіді.
- **Дашборд** — пояснення показників головного екрана.
- **Чек-лист перед запуском** — що перевірити до відкриття магазину.
