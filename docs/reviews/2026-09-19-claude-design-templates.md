# Ревізія шаблонів Claude Design — 2026-09-19

> Крок S7.2 [ранбука](../session-runbook.md). Проєкт Claude Design **store-client Design System**
> (`projectId` у `.design-sync/config.json`), тека `templates/`. Шаблони — стартові макети, з
> яких агент Claude Design починає нові дизайни. Застарілий шаблон тягне застарілу вітрину в кожен
> новий макет. Звірено з develop `501a3aa0`. У проєкті під час ревізії нічого не змінювалось.

**Підсумок:** обидва шаблони (`homepage`, `cart`) — **оновити**. Структура сайту в них упізнавана,
але бренд чужий («volta»), ніша інша (побутова електроніка), є секції, яких на сайті немає, і
відсутнє те, що сайт уже вміє. Оновлює власник у Claude Design промптами нижче: інструмент
синхронізації (`/design-sync`) шаблонів не пише.

Промпти адресовані шаблонам **в проєкті дизайн-системи**. Якщо ті самі сторінки скопійовано в
окремий дизайн-проєкт (напр. «store-client — Pages»), промпт там оновить лише цей макет, а не точку
старту для майбутніх.

Промпт для Claude Design (відкрити шаблон у проєкті й дати агенту):

```
Онови цей шаблон головної під реальний сайт CaseStore — український магазин аксесуарів для смартфонів і техніки Apple (чохли, скло, зарядки, кабелі), не побутової електроніки.
1. Бренд: компонент Logo (без logoUrl) замість «V volta»; email підтримки support@casestore.ua. Увесь текст українською, суми у форматі «1 198 ₴».
2. Шапка — ОДИН липкий рядок: Logo · кнопка «Каталог» + поле «Пошук товарів…» · посилання «Товари», «Блог» · перемикач теми · «Акції» · Обране · Кабінет · Кошик з лічильником. Прибрати «Порівняти», рядок категорій, години роботи, вибір міста й мови. Над шапкою — лише рядок оголошення «Безкоштовна доставка від 1 000 ₴ · Відправка день у день» і телефон «0 800 00 00 00».
3. Секції строго в такому порядку: банер (бічне меню категорій + слайдер з кнопкою паузи) → підбір за моделлю пристрою → промо-плитки → смуга довіри (4 пункти) → категорії → «Популярне» з вкладками → 1–2 тематичні каруселі товарів (на сайті їх налаштовує адмінка) → промо-банер → «Ви переглядали» → підписка з іконками соцмереж → футер. Прибрати «Відгуки покупців», «Топ бренди», окремі «Акційні товари», кнопку чату.
4. Товари — лише через ProductCard (з product.inStock) у сітці 1 колонка нижче 390px / 2 від 390px / 4 від lg; кнопки — Button, мітки — Badge.
5. Адаптивність: контейнер max-w-7xl, нижче lg — бургер-меню замість навігації, нижче 390px ховаються Обране й Кабінет.
6. Жодних #fff, #111 чи rgba(): лише токени (bg-background, text-foreground, bg-primary, text-primary-foreground, bg-card, border-border…); фон сторінки — bg-background.
7. Футер: колонки «Каталог», «Покупцям» (Доставка й оплата, Гарантія та сервіс, Часті питання, Статус замовлення), «Про нас», контакти, юридичні сторінки внизу. Прибрати Кредит і Trade-in.
8. Бічна панель реєстрації: ім'я, прізвище, email, пароль, повтор пароля, згода з умовами; із соцвходів лише Google.
```

## Кошик — `templates/cart/Cart.dc.html`

Сайт: `apps/store-client/src/app/cart/page.tsx` → `widgets/cart/ui/{cart-view,cart-item-row,cart-summary}.tsx`.
Збігається: хлібні крихти, «Кошик · N тов.», «Разом», промокод, «До сплати», примітка про умови,
«Додати ще товари», «Очистити кошик».

| Ділянка           | Шаблон                                                   | Сайт зараз                                                                             | Важливість |
| ----------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------- | ---------- |
| Бренд і шапка     | volta, власна спрощена шапка                             | CaseStore, спільна шапка сайту                                                         | висока     |
| Доставка й оплата | блоки в кошику (місто, НП/кур'єр, «Кредит частинами 0%») | у кошику немає — це `/checkout`                                                        | висока     |
| Додаткові послуги | немає                                                    | «Додаткові пропозиції для цього товару» в рядку + рядок «Додаткові послуги» в підсумку | середня    |
| Стани             | лише «в наявності»                                       | недоступний товар, тост «Повернути» після видалення, порожній кошик                    | середня    |
| Верстка           | фіксовані 1fr + 380px, інлайн-HTML                       | адаптивна; `Button`, `Dialog`, `ApplyDiscount`                                         | середня    |
| Очищення          | одразу                                                   | підтвердження через `Dialog`                                                           | низька     |

Промпт для Claude Design:

```
Онови шаблон кошика під реальний сайт CaseStore. Увесь текст українською.
1. Замість власної шапки volta — та сама шапка, що в шаблоні головної (Logo, один рядок). Товари — аксесуари (чохол для iPhone 15 Pro, захисне скло, зарядка MagSafe 15 Вт), а не iPhone і навушники.
2. Прибрати з кошика блоки «Доставка» і «Оплата» — на сайті вони на сторінці оформлення.
3. Рядок товару: ProductThumb, назва, «В наявності», лічильник кількості, ціна (стара закреслена, якщо акція), видалення; під ним блок «Додаткові пропозиції для цього товару» з 1–2 послугами (напр. «Наклеювання скла — 150 ₴») з перемикачем.
4. Додати стани окремими варіантами: товар недоступний (приглушений рядок + «Видалити»), тост «Товар видалено · Повернути», порожній кошик (іконка, «Кошик порожній», «Схоже, ви ще нічого не додали.», кнопка «До покупок»).
5. «Очистити кошик» відкриває Dialog з підтвердженням (Button variant="outline" «Скасувати» + Button variant="destructive» «Очистити»).
6. Підсумок «Разом»: промокод (Input + Button), «Товари», «Доставка — Безкоштовно», «Додаткові послуги», «До сплати», одна основна Button «Оформити замовлення», примітка про умови.
7. Адаптивність: нижче lg підсумок іде під списком товарів; лише токени, жодних сирих кольорів.
```

## Після оновлення

- Шаблони — не частина синхронізації: `/design-sync` їх не перезаписує й не видаляє. Коли сайт
  знову зміниться (напр. блоки головної з плану 186), ревізію треба повторити — промпт S7.2.
- Коли план 186 зробить порядок секцій даними, шаблон головної варто подати як набір блоків, а не
  як фіксовану послідовність.
- Старий проєкт «Design System» (29.06, 5 статичних HTML) не пов'язаний з кодом — його варто
  архівувати, щоб агента не запустили з ним замість `store-client Design System`.
