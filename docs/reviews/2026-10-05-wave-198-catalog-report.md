## Перевірка

- **Тести смуг.** Після мержу кожної смуги ганялись лише тести її тек: O — 85, N — 133. Повний Jest під час роботи
  інших смуг вибивав пам'ять.
- **Повний Jest наприкінці блоку:** 272 сюїти / 3335 тестів.
  - Під навантаженням упав один тест — `filter-sheet` перевищив таймаут 5 с.
  - Окремо сюїта проходить: 63/63, 12,9 с.
  - Сюїті дано бюджет 15 с (`250986b5`), як раніше `create-product-view`.
- **`npm run typecheck` і `npm run lint`:** exit 0.
- **Playwright і скриншоти не запускались** — рішення власника через нестачу пам'яті.

**Конфлікти мержу:**

- `widgets/index.ts`: смуга O прибрала експорт видаленої сторінки форми послуги, смуга N додала `BrandFormSkeleton`.
  Збережено обидві зміни.
- `eslint-suppressions.json`: кожна смуга прибрала свої застарілі записи, у результаті прибрано всі.

## Аудит «нічого не зникло» і права

Кожна смуга склала перелік дій до й після, з правом на кожну. Окремі кнопки в рядку перейшли в «⋯». Діалоги замінили:

- `window.confirm` — в імпорті й промокодах;
- окремі сторінки форм — у послугах і брендах пристроїв.

Старі адреси форм відкривають діалог.

Кнопки, що раніше не гейтились нічим, тепер гейтяться тим самим ключем, що й API:

| Кнопка                       | Ключ              |
| ---------------------------- | ----------------- |
| «Додати бренд»               | `brands:write`    |
| «Додати промокод»            | `discounts:write` |
| «Додати групу»               | `products:write`  |
| «Редагувати» в огляді товару | `products:write`  |

**Свідомі зміни поведінки:**

- **Імпорт.** Лічильник «що запишемо» тепер рахує так само, як сервер (`countActionable`). Раніше він
  ігнорував зняті позначки — це було дефектом.
- **Послуги.**
  - Опис обмежено 300 символами, як затверджено в Д-ж3. API приймає 2000, тож довший наявний опис доведеться
    скоротити перед збереженням (TASK-1738).
  - Перемикач послуги блокує лише свій рядок; раніше блокував усі.
- **Промокоди.** Статус враховує дати: прострочений код більше не виглядає активним. «Деактивувати» перенесено в
  «⋯ → Вимкнути…» з підтвердженням.
- **Огляд товару.** Кнопку «Переглянути» перейменовано на «Огляд». Опис тепер рендериться, а не показується тегами.
- **Групи товарів.** Перемикач лишився «Активна група» з чесною підказкою: TASK-1031 (видимість групи на вітрині)
  не зроблено.

**Стани «лише перегляд»** для брендів, пристроїв, послуг і промокодів зроблено, але без ключів `:read` вони
недосяжні (TASK-666).
