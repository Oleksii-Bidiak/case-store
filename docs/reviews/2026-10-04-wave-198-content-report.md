**Чому після J і L немає Playwright:**

- Під час прогону після J Claude Code зупинив Jest через критичну нестачу пам'яті.
- Причина — два осиротілі процеси Jest на 4,5 ГБ: завислий прогін смуги D і процес зупиненого мною Jest.
  Їх завершено.
- Після цього власник погодив продовження **без Playwright**. Тому Playwright після J і L не запускався, і
  скриншоти «код проти артборда» для «Контенту» не знято. Обидва кроки треба виконати перед мержем хвилі.

Наприкінці блоку `npm run typecheck` і `npm run lint` повернули exit 0.

**Конфлікти мержу:**

- `row-actions-menu.tsx`: смуги K і J додали однаковий проп під різними назвами. Лишився `tabIndex`.
- `dictionary.ts`: два нові блоки в кінці файлу збережено обидва.
- `eslint-suppressions.json`: кожна смуга прибрала свої застарілі записи, у результаті прибрано всі.

## Аудит «нічого не зникло» і права

Кожна смуга склала перелік дій до й після, з правом на кожну. Що змінилось:

**Змінено місце, але дія лишилась:**

- **Кнопки в рядку → «⋯».** Редагування, публікація й видалення тепер у меню; видалення через AlertDialog
  замість `window.confirm`.
- **«Категорії» блогу.** Була кнопка, стала вкладка розділу «Блог».
- **Форми категорії блогу й FAQ.** Тепер це діалоги поверх списку. Старі адреси `…/new` і `…/[id]/edit`
  відкривають той самий діалог.
- **Збереження форми.** Окремі кнопки «Зберегти» зведено в одну липку панель.
- **Порядок у вибраних вручну товарах каруселі.** Кнопки ↑/↓ замінено перетягуванням за ⠿ і стрілками з
  клавіатури.

**Права:** скрізь лишились ті самі ключі запису розділу. Кнопка «Додати статтю» раніше не гейтилась ніяк,
тепер вимагає `blog:write`.

**Свідомі зміни поведінки:**

- **Каруселі.** Список товарів тепер зберігається кнопкою «Зберегти», а раніше кожна зміна йшла в API одразу.
  Створення — двома запитами: якщо другий упаде, карусель збережеться, а тост скаже, що список ні.
- **Банери.** Текст кнопки без посилання тепер дає помилку під полем (БН8). Такі старі банери не збережуться,
  доки не отримають посилання.
- **Медіатека.** У вибиральнику клік лише виділяє плитку, а вставляє «Використати вибране» (БЛ11).
- **FAQ.** Лічильники рахують за лімітами API 500 / 5000, а не 150 / 1000, як в артборді. Рішення — TASK-1725.
- **Сторінки.** Лічильник рахує довжину збереженого HTML — саме її обмежує API.

**Стани «лише перегляд»** у сторінках, FAQ, блозі, банерах і каруселях зроблено й покрито тестами, але зараз
вони недосяжні: навіть списки вимагають ключ `:write`. Відкриються, коли з'являться ключі `:read` (TASK-666).
