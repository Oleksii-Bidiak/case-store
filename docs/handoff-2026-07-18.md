## 2. Найближча мета: демо на Hetzner без домену → `docs/deploy/03b`

Повний покроковий ранбук уже написаний: **`docs/deploy/03b-test-deploy-no-domain.md`**.
Ключові пастки, перевірені по коду (не повторюй помилок):

- **Продукт: Hetzner _Cloud_ (CX22), НЕ «Webhosting S/M».** Останнє — shared PHP-хостинг без
  root і без Docker.
- **Голий IP не працює** (потрібні 3 піддомени; Caddy не дасть LE на IP; `__Host-` куки по
  HTTP відпадають) → обхід **`nip.io`**: `DOMAIN=<ip-з-дефісами>.nip.io`, нуль змін коду.
- **Деплой демо — вручну на сервері:** `docker compose -f docker-compose.prod.yml up -d --build`
  (обходить GHCR-образи й блокуючий age-бекап CI-джоби). `--build` обов'язковий, бо
  `NEXT_PUBLIC_*` запікаються в образ.
- **Сід НЕ можна запустити в серверному образі** — прод-образ навмисно без `tsx` (виріз
  prune-ом на всіх стадіях) і без `src/`. Сідимо **з ноута через SSH-тунель** до серверного
  Postgres (сідер потребує лише БД, не Meili). `ALLOW_PROD_SEED=true` + власні `ADMIN_SEED_*`.
- **noindex вітрини:** прод-Caddy глушить лише `admin.`/`api.` → після сіду ввімкнути в адмінці
  `noindexSite` (SEO-налаштування) для вітрини.
- **Перехід nip.io → реальний домен = ПЕРЕЗБІРКА образів**, не підміна конфіга (той самий
  `NEXT_PUBLIC_*` bake).

## 5. Пастки середовища (не наступай)

- **guard-bash хук блокує будь-яку bash-команду з підрядком `.env`** (навіть `process.env` у
  grep). Обхід: не друкуй `.env`; для `.env*`-глоба — `.e[n]v*`.
- **guard-destructive** блокує деструктивні `git`/`docker`/`prisma` (force-push, `down -v` через
  тул, `migrate reset` тощо). `git branch -d` (безпечний) — можна.
- **Міграції:** `prisma migrate deploy --config prisma.config.ts` (URL у `prisma.config.ts`) —
  **ніколи `--schema`** (падає з «datasource.url required»).
- **e2e store-api — `--runInBand`** (паралельні воркери діляться Redis-throttler → 429; важчий
  застосунок валить `beforeAll`). store-client/admin повні сьюти теж флейкають паралельно.
- `.env.production.example` — джерело істини для прод-змінних; `backup.sh` сорсить його й падає
  без `AGE_PUBLIC_KEY` (для демо не потрібен — див. 03b).
- Деталі — `AGENTS.md` (single source of truth), `CLAUDE.md`, `docs/README.md` (карта доків).
